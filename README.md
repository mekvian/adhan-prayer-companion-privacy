Public privacy policy and user data deletion notices for the **Adhan Prayer Companion** Android application (`com.aistudio.nurcompanion.vkmqzt`) by **MEKVIAN**.

- **English**: [index.html](https://mekvian.github.io/adhan-prayer-companion-privacy/)

## Summary
- **Zero Remote Storage**: Calculation of prayer times and Qibla direction occurs locally and ephemerally on the user's device. No location data is sent to external servers.
- **No User Account Requirement**: The application operates without requiring registration, credentials, or cloud accounts.
- **Monetization**: Ethical, contextual advertisements provided in accordance with Google Play Developer Policies.
- **Data Deletion**: Complete data removal via device settings or by emailing `mekvian@proton.me`.
